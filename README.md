# Rost Production Tools 4.0

Blender 5.2 add-on: STEP pipeline, CAD Auto-Rig, Rost Light Rig, HUD graphics (Callout, Measure, Section, Volume Cut, Style, FUI), Proximity Alpha, Gradient Mask, scene utilities. All panels live in the N-panel tab **Rost Tools**.

## Installation

1. Download `rost_production_tools.py`.
2. Copy it to `%APPDATA%\Blender Foundation\Blender\5.2\scripts\addons\`.
3. Enable it in Preferences → Add-ons.
4. HUD tools need the HUD library (`HUD_Elements.blend`); set its path in the add-on preferences (**HUD Library**). STEP Pipeline needs the `EXM_Pipeline` scripts and the CADder add-on.
